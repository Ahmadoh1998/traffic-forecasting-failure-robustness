# Outputs

This directory is reserved for artifacts generated by the six analysis notebooks.

Expected subdirectories are created automatically during execution:

```text
outputs/
├── Notebook_1_Inspection_Outputs/
├── Notebook_2_Output/
├── Notebook_3_Output/
├── Notebook_4_Output/
├── Notebook_5_Output/
└── Notebook_6_Output/
```

Generated Parquet datasets, trained models, predictions, figures, tables, and intermediate analysis files are intentionally excluded from normal Git tracking.

For manuscript reproducibility, the final required large artifacts should be distributed through a versioned GitHub Release or another archival repository and documented in the main README.
